# Prompt I used to find duplicate vendors
Tags: #prompts

> You are given a list of vendor records. Group the ones that refer to the same company, even
> when names differ in punctuation, legal suffixes (Ltd, GmbH, Inc.) or abbreviations. For each
> group, return the canonical name and the IDs. Explain any grouping you're unsure about.

Worked well with a few examples first.
